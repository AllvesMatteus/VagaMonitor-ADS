Por que conectar o Telegram?

O VagaMonitor localiza vagas em tempo real no Portal Gupy e permite que você despache qualquer vaga direto para o seu Telegram. Para que a mensagem chegue até você, precisamos saber qual é o seu Bot e o seu Chat ID.

Como conseguir seus dados em menos de 2 minutos:
1
Crie o seu Bot: No Telegram, procure por @BotFather, envie o comando /newbot, siga as instruções e copie o HTTP API Token gerado.
2
Descubra seu Chat ID: Inicie seu bot recém-criado (clique em Começar / Start). Depois, procure pelo bot @userinfobot para ver seu ID numérico.
Não quer configurar agora? Sem problemas! Clique em "Configurar Depois" para navegar nas vagas e preencha quando desejar.
